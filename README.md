# MFND-DCL
This repository contains the implementation code for a multimodal rumor detection model on the Weibo dataset. The pipeline consists of two main stages:﻿

Feature extraction using Chinese-CLIP (text and image embeddings).

Multimodal fusion and classification using a gated cross‑attention network with supervised contrastive learning and multimodal consistency losses.


Dataset：
pheme：https://github.com/azubiaga/pheme-twitter-conversation-collection
weibo：https://drive.google.com/file/d/14VQ7EWPiFeGzxp3XC2DeEHi-BEisDINn/view?usp=sharing
